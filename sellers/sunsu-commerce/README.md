# 순수커머스 유니콘 상품 / KC 전수조사 실행 명세

기존 작업에서는 저장소를 단순히 처음부터 새로 만드는 방식이 아니라, GitHub Actions를 여러 수집 경로로 병렬 실행하고 결과를 진단 JSON과 엑셀로 누적 통합하는 방식을 사용한다.

## 1. 상품 전체 목록 확보

쿠팡 판매자샵을 한 가지 URL만 호출하지 않고 여러 경로로 나눠 수집한다.

- 판매자샵 전체 상품 목록
- 카테고리별 상품 목록
- 검색 인덱스에 노출된 상품
- 상품 상세 URL
- `/vp/products/{productId}` 형태
- itemId·vendorItemId가 포함된 상품 URL
- 모바일/일반 상품 페이지
- 쿠팡 검색 결과에 색인된 상품

각 경로 결과를 합친 뒤 다음 기준으로 정리한다.

- productId 기준 중복 제거
- itemId, vendorItemId 별도 보존
- 상품명 정규화
- 판매 종료·빈 응답·차단 응답 구분
- 차단이나 빈 페이지는 처리 완료로 계산하지 않음

## 2. GitHub Actions 병렬 수집

한 번에 전체를 돌리지 않고 상품을 여러 shard로 나눈다.

예시:

- recover (0)
- recover (1)
- recover (2)
- 각 shard가 쿠팡 상품 페이지와 상품 API를 독립적으로 수집
- 마지막 merge job에서 결과 통합

통합 결과에는 반드시 다음 요약을 남긴다.

```json
{
  "inputCount": 195,
  "recoveredCount": 0,
  "remainingUnresolved": 0,
  "newExactUnicornCount": 0
}
```

## 3. 출판사 판정 3등급

### A. 확정

다음 중 하나가 정확히 일치할 때만 확정한다.

- 쿠팡 상품명에 `(주)유니콘`, `유니콘`, `UNICORN`, `BOOKFRIENDS` 직접 표기
- 쿠팡 필수표기에 제조사·출판사 유니콘 표기
- 동일 ISBN 공식 서점 정보에서 출판사 유니콘 확인
- 상품명, 권수, 조각 수, 구성품까지 동일한 공식 기록 확인

### B. 고신뢰 추론

직접 표기는 없지만 다음이 모두 맞는 경우 별도로 저장한다.

- 동일 상품명
- 동일 시리즈
- 동일 규격·조각 수·권수
- 유니콘 공식 형제 상품 기록 존재

근거를 반드시 기록하며 확정과 분리한다.

### C. 미확정

다음은 유니콘으로 넣지 않는다.

- 비슷한 캐릭터
- 비슷한 시리즈
- 제목 일부만 일치
- 다른 출판사의 동명 상품 존재

## 4. 출판사 후보 확장 검색

다음 키워드와 상품군을 전체 상품에서 재검색한다.

- 유니콘
- (주)유니콘
- 주식회사 유니콘
- UNICORN
- BOOKFRIENDS
- 편집부
- 출판사 미기재
- 제조사 미기재
- 스티커 컬렉션북
- 스티커 퀸 300
- 워터색칠북
- 판퍼즐
- 대판퍼즐
- 퍼즐 2종세트
- 스티커 색칠북
- 캐릭터 색칠북

상품명에 출판사명이 포함된 경우도 따로 추출한다.

## 5. ISBN·공식 도서정보 교차 확인

각 후보 상품은 다음 순서로 확인한다.

1. 정확한 쿠팡 상품명
2. 상품명 정규화
   - 공백 제거
   - 01과 1 통일
   - 출판사·저자 꼬리표 제거
   - 세트 구성 분리
3. ISBN 검색
4. 예스24·교보문고·알라딘 등 공식 도서정보 대조
5. 출판사 유니콘 여부 확인
6. 동일 판본인지 확인

동명 상품이라도 출판사나 권수가 다르면 다른 상품으로 처리한다.

## 6. KC 번호 매핑 원칙

KC 번호는 상품군 단위가 아니라 상품 단위 exact 매핑만 인정한다.

허용:

- 동일 ISBN
- 동일 상품명
- 동일 권수
- 동일 모델명
- 동일 구성품

금지:

- 같은 캐릭터라서 KC 복사
- 같은 시리즈라서 KC 복사
- 유니콘의 다른 상품 KC를 임의 적용
- 퍼즐·색칠북·스티커북끼리 KC 공유

## 7. SafetyKorea 공식 상태 검증

확인된 KC 번호는 SafetyKorea에서 다시 조회해 다음 정보를 저장한다.

- KC 번호
- 제조사
- 모델명
- 상태
- 적합 여부
- 기간만료 여부

유니콘 KC 패턴 참고값:

- CB064H009-2001
- CB064H009-3002
- CB064H009-3003
- CB064H009-4001
- CB064H009-4002
- CB064H009-4003
- CB064H009-8001
- CB064H009-9001
- CB064H009-9002
- CB064H009-9003

이 번호는 새 상품에 자동 적용하지 않는다. 상품별 exact 근거가 있을 때만 연결한다.

`U003E1577-7011`은 유니콘 상품 KC로 사용하지 않고 제외한다.

## 8. 미확인 처리

다음을 구분한다.

- KC 있음
- KC 기간만료
- 상품페이지상 KC 표기 없음
- 검증 불가

페이지 차단, 빈 응답, 상세정보 누락, 검색 실패는 KC 없음이 아니라 검증 불가다.

새 작업에서는 다음 두 값을 분리한다.

- KC 공개표기 없음
- 공식 No-KC 확정

## 9. 진단 파일 누적 저장

```text
diagnostics/
  seller-products.json
  unresolved-products.json
  publisher-candidates.json
  publisher-confirmed.json
  kc-exact-mappings.json
  safetykorea-status.json
  manual-review-batch-01.json
  final-summary.json
```

각 파일 필수 필드:

- productId
- itemId
- vendorItemId
- 상품명
- 판정
- 근거 유형
- 근거 URL
- ISBN
- KC 번호
- KC 상태
- 검증 시각
